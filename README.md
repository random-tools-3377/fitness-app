# Fitness App

An Android app that counts calories and tracks workouts in one place. It is for one person: no
accounts, no sharing, no sync, and no internet.

The design and the house rules are in [CLAUDE.md](CLAUDE.md).

## Installing

Nothing to install yet. The first version, 0.1.0, is the food diary. When it is ready, open the
[Releases page](../../releases) in the phone's browser, download the newest APK, open it and allow
installing from the browser if Android asks.
